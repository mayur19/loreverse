# Contributing

Thank you for improving LoreVerse.

1. Choose an open issue and comment with your intended approach.
2. Keep changes focused and add tests for observable behavior.
3. Run `npm test` and `npm run typecheck`.
4. Explain schema, security and compatibility effects in the pull request.

Do not include real personal information, credentials, private universe content or third-party material without permission. Use fictional usernames and synthetic fixtures.
