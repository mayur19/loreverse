# Delivery roadmap

## Milestone 1 — Foundation

Repository standards, domain primitives, initial migration, structured entries, revision conflicts and request validation.

## Milestone 2 — Creator workspace

Accounts, universe membership, entity editor, custom fields, tags, relations, chronology and draft search.

## Milestone 3 — Editorial workflow

Proposals, comparison, comments, approvals, consistency checks and notifications.

## Milestone 4 — Reader experience

Release composer, spoiler-safe publishing, public search, relationship exploration, collections and reading progress.

## Milestone 5 — Public readiness

Export/import, moderation, accessibility, performance, threat review, deployment documentation and complete browser tests.
